{{< indent 0 >}} Beside my shadow \
{{< indent 1 >}} I gaze across my shoulder \
{{< indent 2 >}} Across a thousand days.

{{< indent 0 >}} There’s a glimpse caught \
{{< indent 0 >}} Of a struggling thing \
{{< indent 0 >}} On the scarlet horizon. \
{{< indent 0 >}} A face \
{{< indent 1 >}} Hands and eyes \
{{< indent 2 >}} And a gait \
{{< indent 3 >}} Like mine.

{{< indent 0 >}} I abhor its viscera \
{{< indent 0 >}} Itself, its entirety. \
{{< indent 0 >}} I know what I see. \
{{< indent 0 >}} I’ve damned it \
{{< indent 0 >}} To these ravenous sands.

{{< indent 0 >}} I remember being convinced \
{{< indent 0 >}} Once of a person \
{{< indent 0 >}} That I was \
{{< indent 0 >}} That I’ll be. \
{{< indent 3 >}} *Always must be*. \
{{< indent 6 >}} *Should be.*

{{< indent 0 >}} This person \
{{< indent 0 >}} Of convictions claimed immaculate \
{{< indent 0 >}} Too too right to ever concede \
{{< indent 9 >}} Not by a strand of hair \
{{< indent 9 >}} Not by the end of a nail.

{{< indent 0 >}} This person, this very one \
{{< indent 1 >}} Too sure of itself \
{{< indent 2 >}} Too sure of everyone else \
{{< indent 3 >}} Too sure of what was \
{{< indent 4 >}} Too sure of what’ll be \
{{< indent 0 >}} Too sure that it was \
{{< indent 0 >}} Too deaf, dumb, and blind \
{{< indent 0 >}} To an utter fact of these sands.

{{< indent 0 >}} Then I look away \
{{< indent 0 >}} To a trail that onward lies. \
{{< indent 0 >}} It is long \
{{< indent 0 >}} Winds like a snake \
{{< indent 0 >}} Under the half-risen sun \
{{< indent 0 >}} Of a still-breaking dawn \
{{< indent 0 >}} Entwined \
{{< indent 0 >}} With a dusty veiling haze \
{{< indent 0 >}} And the boundless shifting sands \
{{< indent 0 >}} But rifts here and there.

{{< indent 0 >}} I sigh. \
{{< indent 0 >}} I walk away.
